# ADR-0003 · 应用仓库：根目录新建 invoice-hub/，旧仓只读不复用

- **状态**：已接受（2026-10-22 用户确认，见实施规划 §1；本文件为落仓全文）
- **关联**：实施规划 §2（目录树与依赖纪律）；清单 §8（历史资产说明 2026-10-22）；FN-A-08/FN-7-11

## 背景

存在两个前一版本工程 `ariba-mock/`（场景断言 S01~S16、Ariba Mock）与 `invoice-platform/`（旧接口门户与契约）。新平台口径（CON-03/04/05 决议、v1.2-candidate 蓝图）与旧仓资产（旧 Schema 路径、不带域案件号、旧契约目录）存在系统性差异；同时旧仓沉淀的方法论（场景断言、L2"第三方不看源码独立接入"判定口径）有真实价值。

## 备选项

| 方案 | 说明 | 否决理由 |
|---|---|---|
| A. 在旧仓演进 | 改 invoice-platform 承接新需求 | 旧契约/旧口径惯性大，"参考"会滑向"复用"，违反 CON 决议与 M0 冻结基线；2026-10-22 用户已明确全新建设 |
| B. 迁移合并 | 拷贝旧代码入新仓再改 | 双轨依赖纪律难以在遗留结构上落地 |
| **C. 全新 `invoice-hub/`（选定）** | 按实施规划 §2 目录树绿地建设；旧仓不动、只读 | 契约、seeds、页面接线需从零产出（已列为 M0~M2 主线工作） |

## 决策

- 应用仓库为项目根下新目录 **`invoice-hub/`**，结构 = 实施规划 §2 目录树（contracts/backend/agent/mcp/web/seeds/docs/tests），M0 增补 `tools/`（自检脚本，P01 明确要求）；
- `web/` 是 `ui-design/` 12 页的**接线副本**：数据入口换 REST API，保留 demo-mode 回退（backend 不可达时回落内嵌 mock，页面仍可独立演示，L2 资产属性不丢）；`ui-design/` 冻结只读，接线改动只发生在 `web/`；
- `contracts/` 为唯一契约事实源（M0 冻结）；旧仓 `contracts/` 路径**禁止引用**；场景断言方法论可参考，代码禁止拷贝；
- 验收口径：`grep -r "ariba-mock\|invoice-platform" invoice-hub/` 仅允许出现在"历史参考"说明性文字中。

## 后果

- **正面**：依赖纪律与枚举单一来源可机械校验；新旧口径物理隔离，杜绝惯性漂移；
- **代价**：api-portal.html 等 UI 页仍含旧契约路径示例文字（页面只读不改）——由本 ADR 与 contracts/CHANGELOG.md 记录"示例随契约升版更新"的同步义务（CON-04 决议）；
- **约束落点**：CLAUDE.md §2/§4；M0 验收⑥；M2 验收（demo-mode 回退必测）。
